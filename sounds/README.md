# Desktop sounds

Drop the real 2001 sound files here with exactly these names and the site plays them.
Missing files fall back to the built-in synthesised versions.

| file | used for | the original it stands for |
| --- | --- | --- |
| startup.wav | the desktop appears after log in | Windows XP Startup.wav |
| logoff.wav | pressing Esc / Leave desk | Windows XP Logoff Sound.wav |
| ding.wav | opening a window | Windows XP Ding.wav |
| chord.wav | an error in the terminal | Windows XP Critical Stop.wav or Windows XP Error.wav |
| balloon.wav | popping a bubble, notifications | Windows XP Balloon.wav |
| start.wav | clicking an icon or a button | Windows XP Start.wav |
| minimize.wav | minimising a window | Windows XP Minimize.wav |
| restore.wav | restoring a window | Windows XP Restore.wav |

They are Microsoft's recordings. Whether to publish them with the site is your call; they are not
committed by this project's author.
